# Development entry points

For work under `whirmill-satssurge-autopilot/`, read that application's
`AGENTS.md` and [the Pi development index](docs/pi/README.md) before changing its
agent harness, tools, queue, recovery, authentication, or Telegram integration.
The index includes versioned upstream documentation and application-specific
contracts. Instructions for this app do not apply to unrelated Umbrel apps.

Preserve unrelated edits and original financial receipts. Publication,
installation, and real financial qualification are separate from local code
implementation and require the corresponding user authority and workflow.
