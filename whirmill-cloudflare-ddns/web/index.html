Checking…

The DNS Edit token is never accepted over this HTTP page. Connect to Umbrel with SSH and run:

umask 077
read -rsp 'Cloudflare API token: ' cloudflare_token; echo
printf '%s' "$cloudflare_token" > /home/umbrel/umbrel/app-data/whirmill-cloudflare-ddns/data/api-token
chmod 600 /home/umbrel/umbrel/app-data/whirmill-cloudflare-ddns/data/api-token
unset cloudflare_token

The token stays out of shell history and must be stored as a regular file with mode 0600. Refresh this page after installing it.
